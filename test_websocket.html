HME WebSocket Alerts Tester

Test real-time connection and push alerts subscription for API Gateway

Prerequisites & Guide

  1. Make sure the backend is running! Start it with: npm run dev or npm run dev:all
  2. Make sure Redis is running! (By default on port 6379). You can run npm run infra or docker-compose up redis -d to launch Redis.
  3. Adjust settings below and click Connect.
  4. Send a heartbeat check using the Send Ping button.
  5. Publish a test alert to Redis to see it instantly pushed to this client!
